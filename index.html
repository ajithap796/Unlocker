Security Policy

Every file selected in this tool is read and processed with the JavaScript already loaded in this page — nothing is uploaded, streamed, or transmitted to any server. Owner-only restrictions are stripped by rebuilding the file's cross-reference table locally; open (user) passwords are verified and decrypted locally, then the pages are re-rendered at your chosen quality preset and reassembled into a fresh, unencrypted PDF.

Saved keyring passwords are stored only in this browser's local storage on this device, and are never sent anywhere. Closing or reloading the tab clears all in-memory document data.

Frequently Asked Questions

How does "Instant Owner Unlock" work?

Many PDF files carry permission-only restrictions (owner passwords) that block printing or editing. This tool rebuilds the file locally, removing the restriction dictionary without re-rendering a single page.

Are open password protected files supported?

Yes. If a file is fully encrypted with an open password, enter it and the tool decrypts the content locally, then re-renders each page at your selected Quality Preset before rebuilding a clean PDF.

Is there a file or size limit?

To keep the browser tab stable, uploads are capped at 20 PDF files per batch. Large files with open passwords take longer, since every page is rendered and rebuilt on your device.

Is this server-less and secure?

Yes. This tool is 100% serverless — document data lives only in this tab's memory and is cleared the moment you close or reload the page.
